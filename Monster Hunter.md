# Project Name: Monster Hunter

## Short Description
A gothic haunted house crawler with procedurally generated levels, monsters of increasing difficulty,
and turn-based movement.

## Story
The monster hunter on their journey to rid the land of monsters is beseeched by the towns people
to clear the manor of evil creatures that plague them. After a long night at the tavern, the hero promises to
save the day - and sets forth into the manor.

## Basic Game Loops
1. Enter a level.
2. Explore, revealing the map.
3. Encounter enemies whom the player fights or flees from.
4. Find gear and use them to strengthen the player (no strict leveling up).
5. Locate the exit to the level - go to 1.

## Minimum Viable Product
1. Create a basic dungeon map
2. Place the player and let them walk around via tile selection
3. Spawn monsters, draw them, and let the player kill them attacking.
4. Add health and a combat system that uses it.
5. Add healing potions.
6. Display a “game over” screen when the player dies.
7. Add a final boss encounter and let the player win by defeating them

4. Add Story (start at town -> travel to forest -> cemetary -> manor grounds -> 1st/2nd/3rd floor)
5. create different monster types
6. Add monster spawn selection based on level
7. Add varied weapons to the game.
8. Include text dialouge
9. Consider some visual effects to make combat more visceral.
10. Inventory selection
11. Ability to save and retain game state
12. Include a journal log of events (maybe after each level, have a entry for the experience)

14. Add stealth

17. Be able to theme sections of the level (i.e. prefab or dictate a room is a wine cellar)
